# AI Vacancy Fit Analyzer — Workflow v0.1

## Цель

Автоматически получать вакансию по ссылке, извлекать её реальный текст, анализировать соответствие кандидату, обрабатывать стоп-факторы, сохранять отчёт и отправлять результат пользователю.

## Входные данные

- ссылка на вакансию;
- профиль кандидата;
- промпт AI Vacancy Fit Analyzer v1.1.

## Workflow

### Trigger

Telegram-бот получает сообщение со ссылкой на вакансию.

### Action 1 — получение источника

1. Проверить, что сообщение содержит ссылку.
2. Открыть исходную страницу.
3. Извлечь название, компанию, обязанности, требования, зарплату, формат и полный текст описания.
4. Если страницу открыть нельзя, запросить текст или скриншоты и не придумывать содержимое.

### Action 2 — AI-анализ

Передать AI-модели:

- извлечённый текст вакансии;
- профиль кандидата;
- ограничения кандидата;
- промпт анализатора версии 1.1.

AI должен разделить прямые доказательства, переносимый опыт, предположения и недостаток информации.

### Condition — холодные звонки

- Если холодные звонки подтверждены, отметить стоп-фактор.
- Если формулировка неоднозначна, отметить риск и сформулировать вопрос работодателю.
- Если холодные звонки отсутствуют, продолжить анализ без стоп-фактора.

### Action 3 — формирование результата

1. Сформировать таблицу соответствия.
2. Добавить вердикт, пробелы, вопросы работодателю и план действий.
3. Разделить рекомендацию отправить отклик и решение принять предложение.
4. Сохранить результат анализа.

### Result

Telegram-бот отправляет пользователю готовый отчёт или сообщение о том, какие данные нужно предоставить.

```text

   └────┼───────────────┘
        ↓
Сформировать и сохранить отчёт
        ↓
Отправить результат пользователю
```

## Error handling и запасные ветки

### Страница вакансии временно не отвечает

1. Выполнить ограниченный retry.
2. Если повторная попытка успешна, продолжить основной workflow.
3. Если ошибка сохраняется, перейти к fallback.

### Страницу невозможно извлечь автоматически

1. Не придумывать содержимое вакансии.
2. Сообщить, что анализ без исходного текста не выполнен.
3. Попросить пользователя прислать текст или скриншоты.
4. Продолжить workflow после получения данных.

### AI-анализ готов, но сохранение не работает

1. Не запускать AI повторно.
2. Удержать готовый отчёт во временном хранилище.
3. Выполнить ограниченный retry сохранения.
4. При повторной ошибке сохранить отчёт локально или в другом доступном хранилище.
5. Отправить готовый анализ пользователю и предупредить, что Google Docs пока не обновлён.
6. Позже повторить только операцию сохранения.
